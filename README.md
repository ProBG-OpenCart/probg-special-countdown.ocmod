# ProBG Special Countdown for OpenCart 3

OCMOD extension that exposes the active special-price start and end dates to the standard OpenCart 3 product template and includes FlipDown countdown assets.

Bulgarian documentation: [README_BG.md](README_BG.md)

## Version

Current version: **1.0**

## Installation

1. Upload `probg-special-countdown-1.0.ocmod.zip` through **Extensions → Installer**.
2. Refresh **Extensions → Modifications**.
3. Add the required Twig output to your theme's product template. See [Readme.txt](Readme.txt) for examples.
