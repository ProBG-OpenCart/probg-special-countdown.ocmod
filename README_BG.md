# ProBG Брояч за специална цена за OpenCart 3

OCMOD разширение, което подава началната и крайната дата на активната специална цена към стандартния продуктов Twig шаблон на OpenCart 3 и включва ресурсите на FlipDown.

English documentation: [README.md](README.md)

## Версия

Текуща версия: **1.0**

## Инсталация

1. Качете `probg-special-countdown-1.0.ocmod.zip` през **Extensions → Installer**.
2. Обновете **Extensions → Modifications**.
3. Добавете необходимия Twig код в продуктовия шаблон на темата. Примери има в [Readme.txt](Readme.txt).
